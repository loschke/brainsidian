# 01_INBOX

Der Eingangskorb. Alles Neue darf hier formlos landen: ein Gedanke, ein Link, eine schnelle Notiz. Nichts muss hier perfekt sein.

Beim nächsten `ingest` oder `lint` wird geleert: jede Notiz wird eingeordnet (nach `08_KNOWLEDGE/` oder `04_PROJECTS/`), verlinkt oder verworfen. Ein leerer Posteingang ist das Ziel, nicht die Ausnahme.
